# Bolos & Gestão V6

## Novidades
- Temas: Claro, Escuro, Rosa, Menta e Oceano. O botão `Tema` alterna as paletas e a escolha fica salva no navegador.
- Guia `Guia de uso e fluxos`: explica a sequência sugerida e oferece dados-base de referência, sem criar cadastros duplicados automaticamente.
- Campos numéricos novos ficam em branco até preenchimento, com placeholders; campos numéricos vazios são convertidos para zero ao salvar para compatibilidade com o banco atual.
- Ajustes de responsividade para dispositivos móveis, tablets, formulários, relatórios e tabelas.

## Fluxo recomendado
1. Cadastre ingredientes, embalagens e bolos prontos em Produtos.
2. Registre compras ou entradas de lote. Evite lançar uma entrada duas vezes.
3. Configure receitas/ficha técnica e rendimento.
4. Registre produção para bolos prontos.
5. Venda no PDV por busca ou código de barras; revise carrinho, desconto e pagamento antes de concluir.
6. Lance despesas e abra/feche caixa com conferência física.
7. Use Relatórios para analisar período, produtos, pagamentos, margem estimada e exportações.

## Observação
O guia fornece dados-base sugeridos, não registros fictícios no banco. Esta versão mantém a configuração Supabase já existente. Não foi possível executar testes de ponta a ponta com a conta/banco real; faça uma venda de teste e valide estoque, caixa e permissões antes do uso operacional.
